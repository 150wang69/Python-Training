论文标题：地区医疗投入与健康效益关联性数据包络分析(DEA)可视化展示系统

摘要：
    医疗资源配置的公平性与效率是衡量地区医疗保障水平的核心指标。本文基于 2015 年至 2024 年十年间我国 31 个省份（不含港澳台）的医疗数据，使用Python 语言综合运用基尼系数、DEA 模型、RSR 秩和比法、K-means 聚类和 Tobit回归等方法，计算并分析我国医疗资源配置的公平性、效率及其外部影响因素，并设计实现了可视化动态展示系统。研究结果表明，基尼系数的结果均小于 0.4，资源配置整体公平性处于合理区间，且呈现“人均优先、总量滞后”的特征；多数省份的 DEA 综合效率未达到最优，纯技术效率和规模效率均保持在 0.9 以上的较高水平，仍有较大改善空间；经 RSR 验证得到的 Spearman 相关系数均为正，证实 DEA 结果具有正相关性；并利用 K-means 聚类将 31 个省份划分为了高、中、低三类效率水平，高水平地区多为东部沿海及部分西部地区，中水平地区多为中西部地区，低水平地区典型代表为北京、浙江等发达地区；Tobit 外部影响因素回归结果显示，人均 GDP 和常住人口的回归系数对效率呈显著负向影响，人均消费、财政教育支出和人口出生率呈显著正向影响。基于研究结论，本文提出优化总量配置、提升综合效率、实施差异化区域策略等政策建议，为医疗资源配置的优化提供理论依据和决策参考。

关键词：医疗资源配置；基尼系数；DEA 模型；RSR 秩和比法；Tobit 回归分析
